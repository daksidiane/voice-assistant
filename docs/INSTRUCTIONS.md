# Руководство пользователя и администратора: Голосовой помощник «Спутник» (SPUTNIK)

## 1. Описание системы

**Спутник** — десктопный голосовой помощник для Windows 10/11 x64, созданный по техническому заданию для работы в фоновом режиме с минимальным потреблением ресурсов CPU и RAM (ориентир 150–200 МБ), что делает его идеальным даже для слабых ноутбуков.

### Ключевые возможности:
- 🟢 **Фоновый режим**: приложение работает без лишних окон, сворачиваясь в системный трей Windows.
- 🎙 **Голосовая активация**: пробуждение по триггер-фразам: **«Спутник»**, **«Ало»**, **«Привет»**.
- 🔊 **Интеллектуальный синтез (TTS)**: вежливый мужской голос (`ru-RU-DmitryNeural`), обращение исключительно на **«Вы»** и **«Сэр»**, вариативность ответов. Имеется 100% офлайн резерв через Windows SAPI.
- ⚡ **Мгновенное аварийное завершение**: глобальное сочетание клавиш **Right Shift + Enter**.
- ⏱ **Планировщик и забота**: напоминания за 1 час и вовремя (голос + всплывающие Toast-уведомления), отслеживание 3+ часов непрерывной работы за ПК с предложением сделать паузу.
- 🌐 **Инфо-сервисы**: время и дата, прогноз погоды, актуальные курсы валют (ЦБ РФ), свежие новости из RSS-лент.
- 🎵 **Мультимедиа**: управление воспроизведением (пауза, следующий/предыдущий трек, громкость) через системные медиа-клавиши Windows.
- 🤖 **ИИ и анализ экрана**: интеграция с LLM (OpenAI / Ollama) для ответов на произвольные вопросы и анализ скриншота активного экрана.
- 🛠 **Пользовательские команды**: добавление любой команды менее чем за 30 секунд без изменения исходного кода.

## 2. Быстрый старт и установка

### Системные требования:
- **ОС**: Windows 10 / Windows 11 (64-bit).
- **Python**: версия 3.10 или новее (при установке Python обязательно отметьте галочку **"Add python.exe to PATH"**).
- **Микрофон** и **динамики/наушники**.

### Шаги установки:
1. Запустите файл `install.bat` двойным кликом (или выполните команду в терминале).
   Скрипт автоматически:
   - создаст изолированное виртуальное окружение `.venv`;
   - установит все необходимые библиотеки из `requirements.txt`;
   - загрузит легковесную русскую модель распознавания речи Vosk (~45 МБ).
2. (Опционально) Скопируйте файл `.env.example` в `.env` и впишите ваши API-ключи:
   - `OPENWEATHER_API_KEY` — ключ погоды (если ключ не указан, погода автоматически берется через открытый API Open-Meteo).
   - `OPENAI_API_KEY` — ключ для произвольных вопросов к ИИ и анализа скриншотов экрана.

### Запуск:
- **`run.bat`** — запуск с открытой консолью (удобно для первого запуска, просмотра логов и отладки).
- **`run_background.bat`** — полностью тихий запуск в фоновом режиме (консоли нет, только иконка в трее Windows).
- **`run.bat --cli`** — интерактивный текстовый режим управления Спутником через клавиатуру без использования микрофона.

## 3. Системный трей и индикация статуса

В правом нижнем углу панели задач Windows отображается круглая иконка Спутника:
- 🟢 **Зеленый круг** — режим ожидания (Спутник спит на минимальном потреблении CPU и слушает кодовые слова: *«Спутник»*, *«Ало»*, *«Привет»*).
- 🔵 **Синий круг** — активный режим (Спутник услышал кодовое слово и слушает вашу команду).
- 🟡 **Желтый круг** — выполнение команды / озвучивание ответа.
- 🔴 **Красный круг** — микрофон выключен (режим паузы).

### Меню правого клика по трею:
- **Статус системы** (текущее состояние).
- **⚙ Настройки...** — открывает графическое окно конфигурации.
- **📅 Планы и напоминания...** — открывает календарь и список задач.
- **⏸ Приостановить / Возобновить** — быстрое отключение/включение микрофона.
- **❌ Завершить работу** — безопасный выход из приложения.

## 4. Как добавить свою команду (Ключевое требование ТЗ)

Пользователь может добавить новую команду **менее чем за 30 секунд** без участия программиста. Поддерживаются 3 простых способа:

### Способ 1: Голосом
Просто произнесите вслух:
> «Спутник, запомни команду **[фраза]** как **[действие/ссылка]**»

*Пример:*
> «Спутник, запомни команду **открыть портал** как **https://portal.mycompany.ru**»

Спутник сохранит команду в базу и сразу подтвердит: *«Команда 'открыть портал' успешно сохранена, сэр»*.

---

### Способ 2: Через конфигурационный файл `custom_commands.json`
Откройте файл `custom_commands.json` в Блокноте и добавьте блок в формате:
```json
{
  "открой корпоративную почту": {
    "action": "open_url",
    "target": "https://mail.company.com",
    "response": "Открываю рабочую почту, сэр."
  },
  "запусти калькулятор": {
    "action": "open_app",
    "target": "calc.exe",
    "response": "Запускаю калькулятор, сэр."
  },
  "как дела": {
    "action": "say",
    "target": "",
    "response": "Все системы функционируют безупречно, сэр."
  }
}
```

#### Доступные типы действий (`action`):
- `open_url` — открыть сайт в браузере (параметр `target` — адрес сайта).
- `open_app` — запустить программу или файл (параметр `target` — имя или путь к `.exe`).
- `say` — только голосовой ответ (параметр `response` — текст ответа).
- `media_play_pause`, `media_next`, `media_prev`, `media_stop`, `volume_up`, `volume_down` — управление мультимедиа и громкостью.


---

### Способ 3: Через окно настроек (GUI)
1. Скажите: *«Спутник, настройки»* или нажмите правой кнопкой мыши на иконку в трее → **«Настройки...»**.
2. В первой вкладке **«Пользовательские команды»**:
   - Введите фразу (например: `открой дашборд`);
   - Выберите действие (`open_url`);
   - Введите цель (`https://my-dashboard.com`);
   - (Опционально) Введите фразу ответа Спутника;
   - Нажмите кнопку **«💾 Сохранить команду»**.
3. Команда сразу же готова к использованию!

## 5. Голосовые команды Спутника

| Направление | Примеры голосовых команд | Результат |
|-------------|--------------------------|-----------|
| **Активация** | «Спутник», «Ало», «Привет» | Спутник откликается: *«Слушаю вас, сэр»* и ждет команду |
| **Управление ПК** | «Спутник, открой блокнот», «открой браузер», «открой проводник», «открой калькулятор» | Запуск соответствующей программы |
| **Сайты** | «Спутник, открой ютуб», «открой вконтакте», «открой сайт github.com» | Открытие страницы в браузере |
| **Поиск** | «Спутник, найди в интернете погоду на выходные», «загугли новости науки» | Поиск запроса в Google |
| **Время и дата** | «Спутник, сколько времени?», «какое сегодня число?», «какой день недели?» | Озвучивание точного времени и даты |
| **Погода** | «Спутник, какая сейчас погода?», «погода в Санкт-Петербурге» | Озвучивание температуры, облачности, ветра и влажности |
| **Курсы валют** | «Спутник, какой курс валют?», «курс доллара» | Официальные курсы ЦБ РФ (USD, EUR, CNY) |
| **Новости** | «Спутник, расскажи новости», «что в мире происходит?» | Сводка свежих заголовков из новостной ленты |
| **Музыка** | «Спутник, пауза», «следующий трек», «предыдущий трек», «громче», «тише» | Управление плеером или YouTube в браузере |
| **События** | «Спутник, запомни: встреча с директором завтра в 15:00» | Сохранение события в расписание |
| **Напоминания** | «Спутник, напомни позвонить врачу через 45 минут» | Автоматическое напоминание голосом + Toast |
| **Просмотр планов**| «Спутник, покажи планы», «какие планы?» | Озвучивание планов и открытие окна событий |
| **Вопросы ИИ** | «Спутник, что такое квантовый компьютер?», «объясни теорию относительности» | Запрос к нейросети и краткий ответ |
| **Анализ экрана**| «Спутник, что тут написано?», «проанализируй этот график» | Снимок экрана и мультимодальный анализ ИИ |
| **Завершение** | «Спутник, выход», «пока», «заверши работу» | Вежливое прощание и закрытие программы |

## 6. Аварийное завершение работы

По требованию ТЗ (п. F2.4), в любой момент времени при нажатии глобальной комбинации:
> **Right Shift + Enter** (Правый Shift + Enter)

программа мгновенно прекращает выполнение и выгружается из памяти.

---

## 7. Конфигурационные файлы

- **`config.json`** — общие параметры (кодовые слова, пути к стандартным программам, параметры звука, города по умолчанию).
- **`custom_commands.json`** — словарь пользовательских команд.
- **`plans.json`** — база запланированных дел и статусы напоминаний.
- **`.env`** — секретные API-ключи (хранится локально, исключен из репозитория).
- **`sputnik.log`** — журнал работы приложения для диагностики.
