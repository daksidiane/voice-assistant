# Локальный голосовой помощник для ПК

Популярные голосовые помощники работают через облако, зависят от интернета и не имеют прямого доступа к файлам Windows.

Этот помощник обрабатывает голос и команды на компьютере пользователя. Запускает программы, открывает сайты и следит за временем работы за экраном.

Данные не обязаны уходить на чужие серверы. Помощник рассчитан на слабый ноутбук.

Имя в этом образце — «Спутник». Windows 10 или 11.

## Установка и запуск

Нужен Python 3.10+ с галочкой «Add Python to PATH».

```cmd
install.bat
```

Скрипт создаст окружение и поставит зависимости. Модель распознавания речи скачается при установке.

Запуск:

```cmd
run.bat
```

Фон, без окна консоли:

```cmd
run_background.bat
```

Только клавиатура, без микрофона:

```cmd
run.bat --cli
```

Ключи для погоды, новостей и произвольных ответов — по желанию. Скопируйте `.env.example` в `.env` и заполните поля. Без ключей помощник всё равно ставит напоминания и открывает программы.

## Как пользоваться

1. Обратитесь по имени: «Спутник», «Ало» или «Привет».
2. Попросите открыть программу или сайт, поставить напоминание, изменить громкость.
3. Статус виден в трее: спит, слушает, обрабатывает, пауза.
4. Если человек сидит за компьютером больше трёх часов, помощник предлагает перерыв.
5. Аварийное выключение: Right Shift + Enter.

Подробный список команд — в документации рядом с проектом, если файл `docs/INSTRUCTIONS.md` есть в вашей копии.
