# Голосовой помощник «Спутник» (SPUTNIK) для Windows 10/11

Десктопное приложение — голосовой помощник «Спутник» для Windows 10/11, работающее в фоновом режиме, оптимизированное под низкое потребление ресурсов CPU/RAM (150–200 МБ) для слабых ноутбуков и компьютеров.

---

## 🚀 Быстрый запуск

1. Запустите скрипт установки:
   ```cmd
   install.bat
   ```
2. Запустите Спутника:
   - В обычном режиме:
     ```cmd
     run.bat
     ```
   - В полностью фоновом режиме (без окна консоли):
     ```cmd
     run_background.bat
     ```
   - В текстовом режиме через клавиатуру (без микрофона):
     ```cmd
     run.bat --cli
     ```

## 📌 Ключевые возможности MVP

| Функция | Описание |
|---------|----------|
| **Голосовая активация** | Кодовые слова: `«Спутник»`, `«Ало»`, `«Привет»` |
| **Синтез речи (TTS)** | Мужской голос `ru-RU-DmitryNeural` (Edge-TTS) + офлайн резерв Windows SAPI |
| **Личность** | Обращение только на **«Вы»** и **«Сэр»**, сдержанный тон, вариативность ответов |
| **Системный трей** | Индикация статуса: 🟢 Спит / 🔵 Слушает команду / 🟡 Обработка / 🔴 Пауза |
| **Управление ПК** | Запуск программ (.exe), открытие сайтов, поиск в Google/Yandex |
| **Мультимедиа** | Пауза, переключение треков, регулировка громкости |
| **Планировщик** | Напоминания за 1 час и вовремя (голос + Toast Windows) |
| **Аналитика и забота** | Отслеживание времени за ПК, предложение перерыва при 3+ часах работы |
| **Инфо-сервисы** | Время и дата, погода, курсы валют (ЦБ РФ), новости (RSS) |
| **ИИ-интеграция** | Произвольные вопросы (LLM) и анализ контекста экрана (скриншот) |
| **Пользовательские команды** | Добавление за ≤ 30 секунд (голосом, в JSON, через окно настроек) |
| **Аварийное завершение** | Горячая клавиша **Right Shift + Enter** |
